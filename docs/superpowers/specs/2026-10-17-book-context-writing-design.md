# 书籍理解与自然表达修订

用户已在对话中确认方向并要求改一版。范围是书名、上传正文两条流程，不改变年度报告首页、字体和现有任务授权机制。

## 设计

- 在既有最终分析中增加可选 book_context 数组，用 characters、logic、intent 表达人物关系、叙事／论证推进与作者主张。每项带实际证据，不强迫无人物书籍填角色。旧结果缺字段仍正常读取。
- 两种输入和独立书评使用同一自包含写作规则。借鉴 daniel-writer 的具体、个人判断与自然趣味，语气跟随原书；成稿后有限清理 AI 套话，不机械禁止文学表达，不产生额外调用。
- 上传在既有 stage0 理解阶段保留人物与逻辑信息，不能只提取操作方法；书名研究在原预算内关注这些线索，不用目录补造故事。
- 正文依次为概览、读懂这本书、核心观点、方法、案例、启发、书评；所有空项隐藏。来源、范围、核验和处理信息集中页尾；应用假设仍就地标明，避免冒充原书。
- 网页、复制、Markdown 与分享图共用结果，分享图仅保留简短来源范围页脚。核验记录保存在结果数据及底部，不能通过精简 UI 升级可信状态。

## 实施与验收

1. 先用来源伪造、旧结果兼容、书评可用证据和 Markdown 主文洁净度建立失败测试。
2. 新增共享写作规则、理解字段校验，并接入两个分析入口及书评。
3. 为阅读区／页尾分离、移动端、复制与真实 Canvas 建立失败测试，再调整展示。
4. 执行现有核心、书名、阅读和服务回归，人工查看新截图。控制测试不等于实际整书质量验收。

本轮不扩大联网研究，不重跑高成本整书任务，不全球安装外部 Skill，不自动提交或 push。正式内容改善需要下一次真实蒸馏验收，不能仅凭提示词和单元测试宣称已读透书。
