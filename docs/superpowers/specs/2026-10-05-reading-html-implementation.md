# 阅读年鉴HTML实施计划

依据：已认可的克制版高保真原型与design.md。用户已授权实现、对抗式审查与测试。

## 实施范围

1. 增加可重复生成的单文件HTML入口，复用原数据与本地真实书封；原atlas、分享和卡片命令保留兼容。
2. 实现阅读统计、月度趋势、分类分布、日期事件、完整书架、单书详情、划线／笔记及有全文证据的书评。
3. 搜索支持中文输入法；分类、状态筛选可清除；详情支持键盘、返回阅读位置与链接。
4. 实现3:4分享预览、单张PNG、整组PNG的ZIP、浏览器PDF打印、Markdown和JSON。
5. 资源内嵌，断网和file协议可用；不在网页发起微信读书请求。按需嵌入具备许可的字体子集，缺少运行时仍能生成系统字体版本。
6. 更新Skill路由与HTML参考文档，明确完整／精选数据范围和全文来源条件，保持短上下文。

## 数据约束

- 只提取交付需要的字段；不复制原始鉴权响应、密钥或整书正文。
- 分布采用实际取得的去重书目，明确其覆盖；不以4本精选替代15本全年。
- 时间线仅纳入真实事件，笔记日期不转换成读完；未知日期和未知进度留空。
- 月份零值、缺失和未到月份分开，图形位置由未舍入秒数计算。
- 未核验完整正文的书评保留等待状态；现有书介不标为全书书评。

## 验证与对抗式审查

- Python：多种输入格式、去重、数据范围、跨年日期、零值／缺失、非法进度、嵌入脚本注入、隐私字段与书评证据条件。
- 浏览器：1440／768／390px、字体、中文长标题、损坏书封、输入法、组合筛选、空态、详情键盘及hash、来源说明、选择／撤销。
- 导出：实际点击按钮、验证PNG尺寸与内容、ZIP成员及CRC、JSON可解析、Markdown来源、PDF分页；断网重复验证。
- 独立于实现过程做一次攻击性复查，以错误数据、超长文本、恶意文本、重复操作和失败条件挑战实现。只记录实际执行结果。

## 交付

通用生成代码、示例、测试、维护文档；用户真实年鉴与验证截图留在被忽略的output目录。完成本地提交，本轮不自动push，不修改已安装Skill目录。
