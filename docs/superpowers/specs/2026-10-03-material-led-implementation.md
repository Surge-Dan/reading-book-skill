# 材料驱动视觉工作流：实现记录

本轮更新项目源码。新建分享任务使用`art_brief.workflow="material-led"`；已有share-3档案保留兼容契约。没有改动用户私人数据、旧6张图片或全局安装目录。

## 已实现

- `art_direction.py`整理有限设计材料包，每页最多四段、每段280字，保留来源与截短标记。不会根据书名或类别选择风格、补全书籍内容或批准方案。
- 每页`artwork`声明材料依据、主意象、视觉语言、实际主素材、阅读路径、图层与字体。新任务缺少这些信息不能确认内容；来源、素材与文字绑定须通过校验。
- `collage_materials.py`提供可重复的原创纸面与设计者指定轮廓的内联裁切原语。没有内置书籍分类版式，不下载或编辑用户参考图。
- 导出器核对声明图层与实际块、实际素材、计划出血，记录图片尺寸与明显放大；核心文字和数据不允许借出血越界。
- Chromium平台字体证据用于拦住未批准回退。显式备用字体可通过；CSS声明不作为字形生效证据。
- 对内容块抽样检查上层不透明素材遮挡，支持普通图片的像素alpha，并防止`pointer-events:none`绕过。SVG、旋转、遮罩和复杂背景的疑点留给实际图片评审；不是完备遮挡检测。
- 行范围细化文字重叠检查，保留旋转竖排兼容；几何记录精度统一以稳定缓存。检查器版本、实际字体证据进入导出指纹。
- Skill入口与艺术指导明确“材料→参考动作→实际素材→字样→逐页构图→实际样张”。拼贴与字体说明按需加载，不加载完整字体库。公开虚构练习演示同书不同材料与陌生书目，不充当模板。

## 使用与边界

在项目Skill目录运行：

```powershell
python -X utf8 scripts/art_direction.py --job output/当前任务/share-job.json --output output/当前任务/design-packet.json
```

助手读取有限材料，提出两个具体方向，记录用户选择，逐页填写`artwork`并制作实际样张。用户不用编辑JSON。只有摘录时不冒写个人收获；没有合适照片时可以选择原创物件或字样。

任意书目可进入流程，视觉适配由助手结合具体材料与用户选择完成；本轮没有实现“输入一个书名，自动理解全书并保证审美”的分类器。技术测试不证明作品的美感或传播效果。新版本的实际组图仍需独立生成、展示和确认，旧样张认可不能迁移。
