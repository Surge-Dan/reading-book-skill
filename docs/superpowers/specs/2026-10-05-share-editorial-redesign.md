# 分享图重设计：阅读杂志特刊

状态：方案待确认，未修改画布代码。

## 目标与当前问题

分享图应让陌生读者看清阅读内容，并愿意收藏、转发。增加丰富度的来源是书封、真实数据、选材、字体和构图的关系。

已查看当前实际封面、统计页与《置身事内》书卡，并核对导出代码：

- 书卡沿用标题、作者、左侧书封、右侧分类、底部一句摘录的固定顺序，短摘录造成下半页大片空白。
- 统计页把一张折线拉满主体，数字与图表缺少第二层阅读线索。
- 封面有插画和花体，但书封、数字与插画各自占据一块，缺少贯穿画面的组织关系。
- 所有内页几乎使用同一标题与分隔线，字体尺度接近，辅助文字在手机缩略图中偏小。

本轮只调整分享画布与其预览，不重采数据、不恢复书评。全部书目可选、默认全选、动态计数和现有导出能力保留。

## 两个方向

|方向|具体处理|取舍|
|---|---|---|
|阅读杂志特刊，推荐|有力度的中文标题、数字排印、书封拼贴、主图与侧栏、局部纸片叠压；数据成为构图骨架|更适合连续组图和不同材料量，需要认真控制每页主次|
|彩色阅读手账|更多纸签、手绘边注、书封贴纸和分散小图；文字沿物件组织|亲近、活泼，但数据多时容易碎，书名与长摘录的阅读效率较低|

推荐采用第一种，保留用户认可的纸面、彩色雾与简笔画，增加编辑排版的力度。整组统一字系与图表语义，各页改变重心和阅读路径。

## 逐页分镜

|页面|主视觉与阅读路径|图表及辅助内容|
|---|---|---|
|封面|年份成为大型排印结构；中文标题跨栏；一组真实书封形成错落书堆，插画连接数字与书封|关键阅读规模形成紧凑数据带；有月度数据时加小型节奏图。代表书封数量随书目与画布空间变化，不能暗示只读过这些书|
|阅读统计|总时长作醒目主读数；紧凑指标带接宽幅月度趋势；旁栏与底部条带形成不同尺度|从原始秒数绘制月度细线，重点标注已知月份中的峰值；有逐书时长时加入短榜。没有时长榜则用有效阅读天数、读过／读完等已有指标重新组织，不新增假数据|
|阅读分布|分类阶梯作为主体，与对应真实书封形成索引关系；标题、分类数量、总分母共同解释图形|数量较少时展示全部类别；较多时展示主要类别并准确汇总其他，列出范围。不同分类有稳定颜色，未知分类明确保留，不猜阅读人格或情绪|
|阅读时间线|用一条贯穿页面的阅读轨迹连接日期、事件与小书封，错落排列而不散乱|按真实日期组织；密集事件先按月份聚合，再展示代表事件，标明展示条数／总条数。有日期覆盖不全时只称“有日期的记录”，不用划线日期冒充读书起点|
|单书卡|真实书封、完整书名与一段主摘录形成明确主角；侧栏或下方加入其他材料，位置随长度重排|可用真实进度、逐书时长、划线／笔记数量；已完整取得且有日期的材料可加记录分布。图表只在数据值得表达时出现，不能每本强塞一张图|

标题可以更自然：封面“这一年，读了这些书”；统计“今年，花在书上的时间”；分布“今年读得最多的是哪些”；时间线“顺着这一年翻回去”。最终依实际范围和数据校准，例如只有部分年内记录时不暗示全年完整。

## 单书卡如何适配任何书

不建立“小说用粉色、社科用蓝色”的类别模板。先看材料，再组织画面：

1. 核查可用材料：真实书封、长短书名、简介、进度、逐书时长、划线、个人笔记、日期及完整性。
2. 选择主角：适合读的摘录、真实个人笔记，或书封与书籍身份。引用保留原文，笔记与摘录分开标注。
3. 按长度决定结构：长摘录优先通栏；短句与书封错落排布；多段材料形成主摘与侧栏。不要把同一句话重复放大来填面积。
4. 用材料增加层次：主摘录之外可选另一段互补摘录、个人笔记、接口简介、真实阅读指标。简介明确标注，不能改成全书总结或用户观点。
5. 配色以整组语义为基础，从书封中选少量合适的辅色；同时核对文字对比度。书封与数据相同但选材不同，构图也可不同。
6. 生成前评估能否放下；长标题、长作者名、长摘录触发重新排版。正文不能靠持续缩小塞进去，未展示全文仍保留于HTML与Markdown。

无划线但有笔记时，以真实个人笔记为主。两者都没有时，放大书封并结合接口简介和已知阅读信息，使用书封色块、局部线描和数字构图完成画面。不伪造引文、心得、评分或阅读日期。材料失败不写成“0条”；没有简介或统计时，允许内容更少，靠物件尺度和排版完成作品。

## 字体、配色与纸面

- 中文标题：优先试排可再分发的思源宋体／Noto Serif SC，使用有明显反差的字重；书名较长时按语义分行。标题起始字号约64–96px，以900px画布试排。
- 正文：中文宋体或清晰的印刷字，主摘录约36–42px；关键图表读数约30–36px，次要说明约26–30px。这些是试排起点，以375px预览的可读性决定最终尺寸。
- 数字：单独处理数值与单位，让大读数承担构图，单位退到旁边；长时长分为小时和分钟，避免整句同字号排印。
- 短批注：仅在有实际内容时用文楷等字族，控制在一两处。花体保留为少量辅助字样，不让英文装饰压过中文主题。
- 字体先核验许可与真实字形，许可允许时对子集内嵌，保证离线导出；字重不能仅靠浏览器合成。预览和导出必须使用同一字体与字距计算。
- 米白为纸面；墨色承担正文；朱红、群青为主强调，芥末黄与灰绿只用于辅助层次。每页保留一个主要强调色，图表分类色跨页一致。
- 纸纹、低对比色雾、局部蜡笔线、书封接地阴影与少量纸签共同增加层次。装饰集中于转折与图文连接位置，避免每个模块都加边框和投影。

密度通过主内容、侧栏、底部信息带和适度叠压提高。不要继续保留书卡下半页的大面积空区，也不要把文字铺满整张。主摘录、图表标签与书名周围保留必要间距。

## 图表与实现链路

继续使用项目已适配的lieflat细线、分类阶梯和逐书刻度表达，以对应真实数据问题；本轮未新增外部图库研究，也未将动画当作静态分享图的丰富度。

实现顺序：核查字段与数据口径 → 建立各页内容包 → 决定主图与辅助内容 → 计算版面与字形 → 绘制图表、书封和原创图案 → 生成同源预览及PNG → 目检与数据验证。

画布渲染从当前大分支拆出独立分享绘制模块；文本测量、图表几何、素材加载与画布布局分别维护。共享视觉职责和真实数据，不能把网页截图压缩成海报。新比例重新组织主次，保留现有1:1、3:4、4:5，不裁切最终画面。

## 验收与成本

先制作封面、统计页、有丰富材料与无划线的两张代表书卡，共四张实际样张；若当前材料没有无划线书，用明确的合成测试材料验证该结构，不能冒充用户记录。展示原图与375px预览，用户认可后扩展其余页面。

- 长书名、长作者、短句、长摘录、无笔记、材料未取得、零书目和较长书单分别检查。
- 图表读数与原始数值一致；缺失不补零，分类合计与分母一致，进度与年度读完不混用。
- 检查文字与图案碰撞、关键内容越界、字号、字体回退、实际PNG比例，以及预览与导出一致。
- 更换书目后所有数量、标题、图表与页面选择动态更新，整组ZIP与当前选择一致。
- 沿用已有真实数据与素材。第一轮不扩大采集、不下载整套字体库、不批量生成插画；确需新增位图时先说明范围与成本。

不以测试通过代替审美认可；分享意愿没有读者测试前不宣称提升了多少。
