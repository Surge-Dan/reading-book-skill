# 分享流程实施清单

用户已认可第二轮样张并授权继续完善代码。沿用已有视觉与轻量方案。

状态：以下六项已完成；验证记录见 [实施结果](2026-10-01-share-validation.md)。

1. 新增独立分享入口：复用规范化，保留精选材料与来源；不默认生成档案或图谱。
2. 用 `share-job.json` 保存内容、短艺术简报、页 ID、两次确认和版本；模型创作页面，脚本维护状态。
3. 一个 `deck.html`，静态 HTML/CSS；脚本等字体和图片、检查文本边界，按页指纹复用 PNG。
4. 确认绑定版本。失败保留上次有效图片；当前变更不能借旧报告宣称完成。局部改动只渲染受影响页，公共 CSS 改动按实际影响处理。
5. 精简 SKILL.md 路由，把艺术指导和分享操作放到两个按需参考；旧档案契约保留。
6. 交付四页完整样例；验证引用、防止旧确认复用、单页重绘和失败回退。另用自然题材检查艺术指导未绑定蓝色或老照片。

边界：不访问真实账号，不安装新渲染依赖，不调用生图，不自动发布或推送。样例技术测试用 `sample-test` 标记确认，不能冒称用户确认了新增文案或真实数据。
