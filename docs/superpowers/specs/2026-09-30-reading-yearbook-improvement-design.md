# 年年阅改进说明：视觉创作优先，轻量运行

初稿：2026-09-30；修订：2026-10-01。代码基线：d6bdd29。

状态：**修订方案待确认，尚未写代码或生成样张。** 本版取代固定暖纸、年轮和完整默认档案流程的建议。

## 1. 产品重心

年年阅首先是一位**基于真实阅读材料创作分享内容的视觉设计师**。用户拿到的是愿意保存、发出去的图片。

- 主场景：小红书图文；主内容：精选书单与真实个人理由。
- 视觉优先，文字保留本页需要说清的重点；感受选填，不代写不存在的经历。
- 风格随材料、用户偏好和情绪改变。现代阅读杂志代表编辑品位，不限定纸张、配色、字体或流派。
- 同一套作品形成一致语言；不同任务重新判断艺术方向。年轮、图表、纹理和角标都是可选元素。
- 私人档案、图谱、深度蒸馏继续保留，**普通分享任务不自动执行这些扩展**。

本轮聚焦艺术指导、两次确认、排印、可靠导出和运行效率。复杂编辑器、风格商城、自动发布和多 Agent 评审不进入默认路径。

## 3. 艺术指导机制

### 每套作品先形成短判断

用真实精选材料写**不超过一屏的艺术简报**：

1. 这次分享让读者看见什么，来自哪条材料。
2. 主要视觉概念与情绪：书与书的对话、兴趣转向、一句值得停留的话等。
3. 主角是字、图像、图文关系还是数据；大胆集中在哪里。
4. 字体关系、色彩倾向、构图逻辑，以及应删掉什么。
5. 整套如何展开、停顿、收束，需要几页才说清。

简报决定设计，不从固定风格菜单抽签。用户给过的方向直接沿用。

### 必须落实的技巧

- **隐喻来自内容**：没有材料依据的隐喻不用。
- **隐形网格与自然非对称**：对齐、比例和重心有依据；允许跨栏、错位、装饰出血，重要文字处于安全区。
- **字体参与构图**：尺度、字重、断句、行长和空白共同工作；处理中文标点、长书名和光学对齐。
- **图文权重不平均**：一页有主要焦点，其他元素成为解释、证据或节奏。
- **整套有呼吸**：疏密和尺度响应内容；相近逻辑可以重复，重点和转折可以打破秩序。
- **删除检验**：线、编号、英文标签、图标、纹理、图表和边框都要有用途。
- **迁移检验**：换一组无关书目后概念仍完全成立，应检查是否泛化；不强制每页不同。

### 用作品证明

实施时先完成**一张封面 + 一张代表内页**，展示手机尺度与原图。检查主角、排印、重心、节奏与材料的联系。若仍只是精致模板，先修正艺术方向，暂停整套制作。

先让用户看见能力，再投入后续工程，不以“9/10”自评宣称艺术质量通过。

## 4. 媒介选择

| 路线 | 适合 | 成本与限制 |
|---|---|---|
| **排印 + 静态 HTML/CSS，默认** | 书单、摘录、感受、精确数字；可编辑和局部改字 | 艺术性来自构图，不来自技术选型 |
| HTML + 一项图像素材，可选 | 作品确需摄影、拼贴、绘画或质感主角 | 素材需合法；生图先说明额外时间与调用 |
| 整页图片模型，可选探索 | 用户明确追求图像工艺并接受重生成 | 文字数字需单独校对，默认不用 |

缺少图像时完成纯排印作品，不交付灰色占位块，不虚构真实书封。不要为了艺术感添加图片。

默认一个推荐方向；用户不满意再针对性探索。多方向比较只做封面试稿，不同时生成几套完整卡组。

## 5. 轻量用户流程

沿用已经确认的两次确认：

1. **准备与内容确认**：读取已有材料，提出书目、短文与艺术概念；缺少感受时选填一句。用户确认一次，包含原话和引用。
2. **视觉确认**：展示封面与代表内页的实际预览，用户确认一次。
3. **完成与交付**：完成其余页面，检查实际成图，交付编号 PNG、可编辑源与短发布文案。

正常过程不编辑 JSON、不逐页询问、不重复解释方法论。重大内容或风格变化回到对应确认点；技术性修复直接处理。

页数服从材料。普通分享建议先规划**4–6 页**，可少可多，不凑固定栏目。尺寸先沿用 900×1200 / 3:4；以约 375px 手机显示下舒适阅读为准，不用绝对字号代替视觉检查。

完整档案、额外尺寸与深度蒸馏按需追加，并先说明增量工作。

## 6. Skill 管理与成本

### 管理范围与依赖

管理本项目的入口、参考、脚本和运行路径。将外部 Skill 的有效方法蒸馏为自包含指导；普通生成不串联 huashu-design、frontend-design、brainstorming、grill-me 等开发阶段 Skill。保留现有自动发现策略，描述聚焦阅读分享，避免吸引无关设计任务。

### 渐进加载

当前入口实测为 68 行、3110 字符，已经较短。成本治理重点是缩小默认执行范围、减少参考和原始数据加载、避免重复创作；不能把压缩入口字数当作主要节省来源。这里的字符数不是 token 数。

| 当前任务 | 加载 | 默认省略 |
|---|---|---|
| 新建分享卡组 | 短入口、艺术指导、分享交付规则 | 研究全文、其他风格目录、全书档案与蒸馏 |
| 改一页 | 当前简报、该页源内容、变更规则 | 全部页面全文、重新调研和采集 |
| 真实数据采集 | 对应官方接口说明与脚本 | 不相关 API 和其他模式 |
| 完整档案 / 蒸馏 | 对应已有路由 | 分享设计参考，除非同时需要 |
| 导出 / 复核 | 执行脚本，只接收摘要和失败项 | 全部源码和成功日志 |

建议入口约 1000 中文字以内、艺术指导约 1500 中文字以内。这是维护目标，不是格式标准或 token 保证。规则只存一处，引用尽量一层；精简前检查调用关系，不按文件长度删除能力。研究放在 docs，默认不读。

### 将模型资源花在视觉判断

- 规范化、去重、来源索引、批量截图与布局检查交给脚本。
- 模型接收精简事实、选中书籍和必要片段；原始 JSON 留本地。摘要标明缺失和覆盖，不把片段冒充全文。
- 一次确定艺术方向，一次完成其余页面，不每页重复长分析或全局 CSS。
- 一份 deck.html 共享基础样式，每页有稳定 ID 与独立构图；改一页只更新对应区域，渲染批量执行。
- 默认单个主 Agent，不增加设计师、文案师、评审师的上下文复制。
- 普通任务不联网查新风格；确需素材时限定检索范围，失败后不持续扩搜。

### 减少重复操作与修复

复用已有规范化数据，视觉修改不重新请求微信读书。无数据时先检查年度统计与候选书目，确定分享子集。

按精选书定向采集作为后续可选优化，必须记录请求范围与完整性。“这些书已采集完整”不能被写成“全年书目已采集完整”；年度总量只来自可靠统计。首个视觉验证阶段不重写采集器。

图片绑定源文件、素材、字体和导出设置版本，成功页复用，只修失败或受影响页。一次针对性修复后仍失败，明确原因并保留草稿；进一步探索先说明成本，不无限尝试。

### 成本可观察

记录参考读取量、模型/生图调用（环境可见时）、页数、修复轮数与分阶段耗时。环境有真实 token 数据才使用；否则注明代理指标，不能报告虚构 token 或节省百分比。只在成本超出计划或完成时给短摘要。

更多方向、图像素材、页数与全书分析均说明增量工作，用户接受后再扩展。质量不足优先改关键页，不靠增加规则和调用制造认真。

## 7. 最小实现与交付

复用现有可信数据与来源规则。一个轻量任务文件保存内容、来源、简报、确认版本、页面状态和素材；一份验证报告记录结果，不为每项选择建立独立文档或复杂状态系统。

分享目录包含：

- share-job.json：内容、来源、艺术简报、确认和页面版本。
- deck.html：精确文字与逐页构图，共享基础样式。
- images/：顺序清楚的 PNG。
- caption.md：短发布文案。
- validation-report.json：数据、文件、布局与目检摘要。
- revisions/：发生修订时保存。

内容与视觉确认绑定版本，图片必须对应当前源文件。数据不完整、确认失效或 PNG 失败只能保留草稿 / HTML 可用状态；不能称为完成分享包，也不表示已发布。

优先复用导出和验证脚本，只补字体/图片等待、正文裁切、页脚重叠、版本映射和失败摘要。检查允许有意的装饰出血，重要文字不可裁切。

分享文案不显示评分、E0–E3、裸来源 ID 和内部技术状态；样例、草稿和截至日期仍诚实表达。原始数据和密钥不进入分享包。用户补充感受单独标记，不混入历史笔记与统计。

## 8. 验收

**视觉**：封面主角明确，缩略图能辨认重点；手机正文舒适，标点、换行、对齐与重心经过实看；全套协调而有节奏，变化来自内容；无用装饰删掉。两张试做页获得认可后才完成整套。

**正确性**：数字和引用可追溯，感受不伪造；样例、缺失和期间未结束如实标记。零阅读不拼凑，少书减少页数，长文改构图或拆页。图片版本一致、素材就绪，无非预期正文裁切和破图；失败不覆盖此前有效作品。

**效率**：正常两次确认，无默认外部 Skill 链、多 Agent 或研究全文加载；不重复采集，不因一页修改重做整套。用样例测读取量、耗时和修复次数，再定成本目标。

改造后以同一组精选材料、相同交付页数对比旧路径和新路径，再测试一次单页改字。分别记录首轮生成与局部修改成本，避免仅因少生成页面就宣称效率提升。当前未实测，成本约束仍是实施要求。

## 9. 实施顺序

1. **视觉能力验证**：方案确认后，用已有样例做一张封面与一张内页，不先搭框架；以作品证明路线。
2. **蒸馏艺术指导与 Skill 路由**：根据试做有效方法精简入口与必要参考，整理默认路径、依赖和成本边界。
3. **轻量生成、导出与修订**：复用脚本，补排印与版本验收，接上两次确认。
4. **完整样例验证**：完成一套，再用另一组题材检验风格是否响应内容；按实际瓶颈优化采集和成本。

第一阶段效果未获认可时停止后续工程。真实账号、深度蒸馏、更多媒介与复杂探索按需执行。
