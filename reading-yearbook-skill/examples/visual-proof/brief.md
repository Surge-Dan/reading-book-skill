# 视觉试稿：给判断留一点空白

状态：用户已否定这轮视觉与文字；保留用于对照，不作为通过样例。当前改稿见 [第二轮](../visual-proof-v2/brief.md)。尚未接入正式生成流程。

实施顺序：两页静态 HTML → 本地渲染与检查 → 用户视觉确认 → 再集成 Skill 路由和分享流程。前三项已进行到视觉确认点。

## 本次艺术判断

- 内容：选择、工作与提问的三本书，都涉及暴露假设、保留反方、验证问题。用“给判断留一点空白”概括，属于编辑标题。
- 主角：文字与空白。封面把“空”“白”之间的空间变成标题的一部分；内页在“但”处换位置，表现句意转折。
- 关系：封面深绿、内页浅灰；中文宋体负责主句，无衬线负责书目与笔记。青黄色只强调空白及“自欺”。这些选择仅适用于本次题材。
- 减法：不添加虚构书封、年度大数字、背景纹理、装饰图标或英文标签。
- 范围：900×1200，封面 + 代表内页；一个方向；不生成其他页，不访问真实账号，不调用生图。

## 本地渲染

`render.cjs` 只用于这次试稿。复用已有 Node Playwright 包及本机浏览器，不下载依赖。指定包路径与浏览器路径执行：

```text
node render.cjs --playwright-path <现有 playwright 包路径> --browser <浏览器可执行文件路径>
```

等待字体和图片就绪，检查标记文字的边界与重叠，生成两张 PNG、375px 阅读预览和验证报告。自动检查不能替代视觉判断。中文字体使用本机 Noto Serif SC / Noto Sans SC；其他机器若缺少它们，会使用后备字体，需重新审阅排版。

本次验证：两张 PNG 均为 900×1200；标记文字边界与区域重叠检查通过。已人工查看原图与 375px 预览，未发现正文裁切，推荐理由在手机预览约为 14px；书目与样例标记为次要信息，尺寸更小。用户的审美确认仍待完成，不以自动检查通过代替认可。验证报告记录当前 HTML 和 PNG 的 SHA-256，便于识别后续修改后的旧图片。
