# 拼贴的材料与构图

> 历史独立组图的设计资料。当前年鉴、组图和单书卡统一使用[HTML年鉴流程](html-yearbook.md)及网页内分享渲染器；不把本文的artwork、deck或确认命令作为默认要求。仅在用户明确要修改旧工程或改变当前艺术方向时定向参考。

只在用户选择拼贴时读。不要把这份说明变成所有书目的默认风格。

## 从内容到画面

先提炼一条可核对的内容关系，再决定视觉操作。对照可以让两种声音相邻或分开；局部观察可以裁出同一对象的两个尺度；时间可以沿真实记录展开；犹豫或省略可以通过空位表达。操作必须有当前材料的依据，不凭书名猜物件。

选一个主物件，考虑它的轮廓、空白、与文字的尺度关系。允许正文在安静的区域保持规整，主物件承担不规则构图。胶带、撕边、印章、英文小字不是必需品；删掉不改变阅读的装饰。

层次可以来自：主体与局部、印刷与短笔记、光面与纤维纸、完整形状与裁切后的负形。不是每页把这些全部用上。手写字只是一种设计声音，不是用户真实笔迹。

## 原创与登记

参考图用于拆解手法；素材必须有明确来源和使用依据，保存本地版本并登记sha256。没有合适照片时选原创SVG物件或纯字体方向，不假造真实书封，不强迫用户每本书都找照片。

`scripts/collage_materials.py`提供两个可选原语：

```python
from collage_materials import paper, cutout
paper_svg = paper(600, 400, seed=17, color='#eee6d6', roughness=3)
object_svg = cutout('assets/object.png', 420, 520,
                    uid='object-cut', contour='M0 40 L360 0 L420 460 L60 520 Z')
```

`paper`用固定种子生成原创纸面；`cutout`由设计者给出实际轮廓，内联到HTML后仍依赖已登记图片。它们不决定主物件、配色或版面，不编辑用户参考图。外部SVG若包含其他资源，先转成自包含本地素材，导出不临时联网。

## 构图与校对

- 主物件可以出血；有文字或数据的图层不借“拼贴”越界。计划出血要写具体理由。
- 图像压文字时，主要文字留在可读区域；保护中文标点和完整句子，不能用阴影补救遮字。
- 保持一个主重心和明确阅读路径，非对称也有对齐依据。纸张倾斜不意味着正文也必须倾斜。
- 先看缩略图的图文关系，再看375px预览的正文。分镜足够不代表实际成品足够。

导出器检查声明图层、字体和抽样遮挡；旋转、SVG、遮罩及复杂混合效果会留下需目检项。看实际PNG确认轮廓、叠印、边缘和文字，没有自动审美分数。材料不足就简化有依据的表达，不凑图层、不编造阅读感受。
