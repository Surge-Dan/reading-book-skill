# HTML阅读年鉴操作

## 任务与默认产物

一份单文件HTML，包含年度统计、完整月份趋势、已载入书籍的主分类分布、真实事件时间线、可筛选书架、书评／划线／笔记及分享导出。用户只要图片时仍走share-workflow，不扩大任务。

复用已有记录；先确认尚未明确的年份、范围与视觉方向。用户已认可原型不重复问风格。HTML本身无图片比例，分享出口首次确认比例；支持3:4、1:1与4:5，不机械裁图。

## 生成

```powershell
python -X utf8 scripts/build_reading_html.py --input reading-data.json --output output/reading/index.html
```

接受原始`shelf/stats/book_details`、规范化`summary/books`或已有`share-job.json`。已有分享任务包通常仅有精选书，用`--annual-snapshot`补充年内书目，不能直接加入整个书架。年度快照包含`annual.readLongest`、`shelf.books`与可选`non_ranked_progress`；后者只纳入实际开始阅读且末次阅读在本年的书。快照需通过显式year或annual.readTimes日期核验年份，跨年快照拒绝合并。

`--covers covers.json`映射书籍ID到本地PNG/JPEG/WebP路径，路径相对covers.json。已有真实书封内嵌到HTML；缺少时显示明确的文字封面，不生成伪装成真实版本的封面。不自动请求远程书封或在线字体。

缺少读完、进度、日期或逐书时长时显示未知，不从年度总量分摊。每本书保留一个来源主分类，层级分类第一层用于分布，原始分类保留在数据中。书目覆盖和材料覆盖分别检查；有15本身份不意味着15本都有笔记或全文。

资源、代码及书封均内嵌；字体优先本机Noto中文字族，其他设备回退系统中文字体。当前生成器未内嵌字体文件；若需跨设备字形一致，取得可再分发字体并做子集后再内嵌，不暗示已完成。

## 全文书评

微信读书提供阅读记录、书籍信息、划线与笔记；不要假设它提供完整正文。需要全书评价时主动检索：作者／出版社公开版本、公共领域或开放许可书库、可用的用户授权来源。初次每本最多两组针对作者与版本的查询、核验五个候选，暂时网络失败最多重试一次；找不到则保留“等待全文”，继续处理其他书。

核验书名、作者、版本、开头／结尾、目录和章节覆盖，记录访问依据和来源。目录、试读、其他书评不能当全文。正文留在私人目录；分章节读取和缓存，完成结构理解后写书评并回查判断对应章节。个人体验只来自真实笔记，不把生成评价写成用户经历。

在规范化输入的书籍对象中提交：

```json
{"full_text_review":{"status":"verified","coverage":"complete","source":"完整正文来源","version":"核验版本","body":"书评正文","citations":["第2章：判断依据","第8章：判断依据"]}}
```

只有处理完整正文且有来源、正文与章节依据时生成这些字段。脚本检查字段条件，不会替代Agent核验正文。没有字段时详情诚实显示等待状态，不将旧书介或片段归纳冒充全书书评。

## 图表

月度图适配lieflat-charts Basics B2/F2真实骨架：日历地板、细线、逐点、峰值读数；月份取代日序列，原始秒数决定位置，缺失断线，真实零值落在基线，尚未到的月份不入图。选择月份可用键盘，另有准确时长表。

分布用已载入去重书目计数，进度未知不归“在读”。时间线只纳入有真实日期的划线、笔记、明确初读与读完事件；笔记日期不转换成开始日期。没有逐日数据不制作热力图。

lieflat图表代码保留PolyForm Noncommercial 1.0.0完整许可，内嵌到HTML来源区，商业用途需满足原许可条件。新配色遵循用户认可方向，不偷偷固化到所有年鉴。

## 分享与导出

先预览独立分享画布，再选择封面／统计／分布／时间线／单书卡。可从详情或摘录选择具体划线加入分享，支持撤销。Canvas输出本地PNG，整组为PNG的ZIP；没有安装Playwright也能在用户浏览器中导出。分享页长文字以省略号明确截短，完整内容保留在HTML与Markdown。

PDF打开浏览器打印对话框，包含当前筛选书架及对应详情、书评与笔记，不显示网页控件。Markdown与JSON包含年鉴已载入内容与来源，JSON不重复内嵌封面；都不带密钥、鉴权响应或整本正文。

字体／书封／画布未就绪或生成失败时停止该次导出，保留选择并展示原因，不用旧文件报成功。页面制作后实际测试file协议及离线浏览，点击每个导出按钮核验文件。

## 验证与成本

只读本参考及当前数据，不同时加载所有设计和gallery。既有统计不重采，章节按版本与摘要缓存，字体调整不重读全书。先做一篇有合格全文的书评再扩批；批量检索和OCR需要先报告范围，不能把UI改造变成全年全文处理任务。

测试1440／768／390px，长中文、空记录、未知状态、输入法、筛选清除、键盘与减少动态效果。核验图表位置和数据、PNG尺寸、ZIP成员CRC、打印分页、Markdown来源、JSON结构，检查网络请求和控制台。对抗式审查另做一轮：恶意文本、重复记录、缺失月份、坏书封、连续导出、空选择和数据口径冲突。
