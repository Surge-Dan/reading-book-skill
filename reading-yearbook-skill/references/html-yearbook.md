# HTML阅读年鉴操作

## 任务与默认产物

一份单文件HTML，包含年度统计、完整月份趋势、已载入书籍的主分类分布、真实事件时间线、可筛选书架、划线／个人笔记及分享导出。用户只要图片时仍走share-workflow，不扩大任务。

默认用户只需安装Skill并接入有效微信读书接口，助手完成采集和网页交付。年份未指定默认本年并说明；用户指定范围或方向时沿用，不重复确认。有效授权和接口可用是前提，鉴权失败不拿示例冒充真实记录。HTML本身无图片比例，分享出口首次确认比例；支持3:4、1:1与4:5，不机械裁图。

## 自动交付入口

助手运行，用户无需填写JSON：

```powershell
python -X utf8 scripts/generate_reading_html.py --year 2026 --output output/reading-2026/index.html
```

Key从环境变量读取，不进入参数或交付。私人缓存按授权、年份和日期隔离；只复用当前用户的有效材料。新采集超过100本时先返回`needs_scope_confirmation`并说明范围；用户明确同意后才加`--allow-large-yearbook`，已有完整材料不受此限制。年度排行已覆盖官方读过总数时跳过额外候选扫描；否则结合书架与分页笔记本发现候选，再以实际进度和本年日期核实。完整笔记逐书采集，零记录有效；覆盖不足如实说明。可用`--annual-snapshot`、`--materials`和`--covers`复用已核验材料，不为视觉修改重采。

正式封面缺失时保留上一版，另输出明确的`index-draft.html`，说明缺失；材料局部失败仍交付可用网页并注明状态，不能称材料齐全。同一授权与年份的上次笔记保存在私人状态缓存中；刷新失败保留已有内容，成功核查为零才清空。有效接口也不保证返回逐日数据或所有书目；未知不补零。脚本退出码0为完整，3为部分，2为阻塞。交付前由助手使用已有浏览器测试离线文件及导出，不要求用户安装运行时。

## 使用已有材料构建

```powershell
python -X utf8 scripts/build_reading_html.py --input reading-data.json --output output/reading/index.html
```

接受原始`shelf/stats/book_details`、规范化`summary/books`或已有`share-job.json`。已有分享任务包通常仅有精选书，用`--annual-snapshot`补充年内书目，不能直接加入整个书架。年度快照包含`annual.readLongest`、`shelf.books`与可选`non_ranked_progress`；后者只纳入实际开始阅读且末次阅读在本年的书。快照需通过显式year或annual.readTimes日期核验年份，跨年快照拒绝合并。

`--covers covers.json`映射书籍ID到本地PNG/JPEG/WebP路径，路径相对covers.json。正式年鉴使用`--require-all-covers`，有任何真实封面缺失时停止生成，保留上一版；文字封面仅用于草稿、示例或坏图恢复，不能把大批占位封面当正式交付。网页和离线构建本身不请求远程封面，材料采集阶段先取得来源中的真实封面并内嵌，不生成伪装成真实版本的封面。

### 补齐书籍材料

已有组图任务只保留精选片段，不能将其当成完整年鉴的笔记输入。补全年内书目后，逐本核实封面、当前进度、完整划线及个人想法；只请求已确认的书，不重采整个书架。使用：

```powershell
python -X utf8 scripts/collect_html_materials.py --input share-job.json --annual-snapshot annual-snapshot.json --output private/html-materials
python -X utf8 scripts/build_reading_html.py --input share-job.json --annual-snapshot annual-snapshot.json --book-materials private/html-materials/materials.json --covers private/html-materials/covers.json --require-all-covers --output output/reading/index.html
```

采集脚本读取环境变量中的Key，两个并发任务、复用有效缓存、按游标拉取全部个人想法；单书最多20页，超过时停止扩批，版本升级或鉴权失败停止新请求。可用`--legacy-cache`复用旧的`bookId-highlights.json`／`bookId-thoughts.json`。缓存及封面留在私人目录，错误状态不写成空笔记。构建器只合并当前年鉴已有书籍，不让额外书目混入。

详情默认载入该书全部历史记录，并注明范围；年度时间线只取本年事件。确认接口完整返回0条时写“已核查，无记录”，请求失败或只取了片段时写“未完整载入”。年度统计优先读取官方`readStat/readDays/totalReadTime`及月度分桶；当前进度100%的筛选和官方年度读完汇总分别保留，不能为了对齐数字篡改任何一方。刷新统计同时更新采集日期。划线区支持按书籍筛选，导出保留材料范围。

缺少读完、进度、日期或逐书时长时显示未知，不从年度总量分摊。每本书保留一个来源主分类，层级分类第一层用于分布，原始分类保留在数据中。书目覆盖和材料覆盖分别检查；有15本身份不意味着15本都有划线或个人笔记。

资源、代码及书封均内嵌；字体优先本机Noto中文字族，其他设备回退系统中文字体。当前生成器未内嵌字体文件；若需跨设备字形一致，取得可再分发字体并做子集后再内嵌，不暗示已完成。

当前示例采用用户认可的彩色纸本方向：花体Reading、宋体标题、红蜡笔书页、蓝色眼镜、米白纸纹及红蓝黄色云。固定英文装饰字样已排印成透明图片，字体文件不分发；中文、统计、书名保持可选文本。艺术素材与业务数据分离，网页和分享画布复用，HTML只内嵌一次。换风格时先重做构图与素材，再调整`reading-art.css`，不要只改色值。可用`--art-assets art.json`替换素材，JSON字段为`hero`、`reading`、`rhythm`，路径相对JSON；未指定字段沿用当前素材。这个示例不是风格选择器，不按书名自动套皮肤。

## 无材料与失败处理

有划线时展示原文摘录；只有个人笔记时主区展示想法并标注“我的笔记”。两者都没有时保留完整书架与真实统计，只显示一次温和说明；单书分享用书封、作者、分类和已知进度，不把“未载入”等系统说明印在分享图上。

每本书详情只展开有内容的材料区，缺少的材料给出简短状态。已完整核查的零记录与请求失败必须不同；失败保留已有内容，说明可让助手重新同步。没有年内书目时隐藏无用筛选和翻页，明确年份及零记录／未取得的区别。时间线只用真实日期，不因无笔记虚构开始阅读或读完事件。

网页、打印、Markdown、JSON不包含生成书评、全文来源占位或全文搜索状态；也不自动开展全文检索。书籍简介来自接口，与用户笔记分开。

## 纸面与控件

参考图的蓝色外缘、暖色细边线、大范围低对比色雾、纸纤维与铅笔线共同建立质感。色雾跨章节分布，不给每个组件加渐变。花体、中文宋体和紧凑正文保持层级；简笔画放在留白与章节连接处，不覆盖文字。真实数据与艺术素材分别维护；当前纸面是示例方向，不强制所有用户使用相同风格。

搜索用SVG并按几何中心对齐；书架展开按钮居中。书籍和比例选择采用统一纸色浮层，支持方向键、Home/End、Escape、Tab、点击外部关闭、长书名换行和滚动。手机浮层不越界；减少动态与打印不受装饰影响。

## 图表

月度图适配lieflat-charts Basics B2/F2真实骨架：日历地板、细线、逐点、峰值读数；月份取代日序列，原始秒数决定位置，缺失断线，真实零值落在基线，尚未到的月份不入图。选择月份可用键盘，另有准确时长表。

分类采用B1/F1 Rung Bars，一档一本，阶梯可数，点击或键盘选择后筛选书架。逐书投入采用C1/F5 Tick Rows，固定时间单位（默认30分钟，最长一行超过80格时提高单位），尾数按比例短横线表示；完整准确秒数另有表格。时长未知不补零，时长排行不代表喜爱排行。三图沿用原gallery的draw/pop/fade与错峰时序，滚入播放、独立按钮重播；连续重播取消旧动画。缩放只重绘最终帧，不能把图停在透明初始状态。减少动态效果与打印立即显示完整图，Canvas直接绘制最终数据，不截动画中间帧。

分布用已载入去重书目计数，进度未知不归“在读”。时间线只纳入有真实日期的划线、笔记、明确初读与读完事件；笔记日期不转换成开始日期。没有逐日数据不制作热力图。

lieflat图表代码保留PolyForm Noncommercial 1.0.0完整许可，内嵌到HTML来源区，商业用途需满足原许可条件。新配色遵循用户认可方向，不偷偷固化到所有年鉴。

## 分享与导出

分享出口从当前年鉴全部已载入书目建立单书卡，不按精选标记、书架搜索或分页裁减。封面、阅读统计、阅读分布、阅读时间线及全部书籍默认勾选，也允许用户取消。四张概览单独展示；书籍使用纸色多选浮层，支持搜索书名／作者、勾选、独立预览、全选、清空和完成。搜索只筛选可见行，不改变选择；全选和清空只作用于书籍。Escape关闭并恢复触发器焦点，浮层适配移动端并保持在视口内。

书籍数量、已选书籍数、已选页数、总页数均从实际数据和选择状态计算，禁止复用示例数量。预览不改变勾选；整组ZIP只包含当前选中页面，成员数必须与已选页数一致。导出期间锁定调整，失败保留选择并解锁重试。零书目禁用书籍选择器，仍可预览与导出四张概览；没有分类、月度时长或日期事件时展示对应真实空态，不补零或捏造记录。

先预览独立分享画布，再调整页面选择。可从详情或摘录选择具体划线加入分享，支持撤销。Canvas输出本地PNG，整组为PNG的ZIP；没有安装Playwright也能在用户浏览器中导出。分享页长文字以省略号明确截短，完整内容保留在HTML与Markdown。

PDF打开浏览器打印对话框，包含当前筛选书架及对应详情、划线与笔记，不显示网页控件。Markdown与JSON包含年鉴已载入内容与来源，JSON不重复内嵌封面；都不带密钥、鉴权响应或整本正文。

字体／书封／画布未就绪或生成失败时停止该次导出，保留选择并展示原因，不用旧文件报成功。页面制作后实际测试file协议及离线浏览，点击每个导出按钮核验文件。

## 验证与成本

只读本参考及当前数据，不同时加载所有设计和gallery。既有统计不重采，视觉修改不重读记录。只采年鉴候选书，默认不检索全文或OCR；很大书架／超过分页上限时说明范围与覆盖，不能无限扩批。

测试1440／768／390px，长中文、空记录、未知状态、输入法、筛选清除、键盘与减少动态效果。核验图表位置和数据、PNG尺寸、ZIP成员CRC、打印分页、Markdown来源、JSON结构，检查网络请求和控制台。对抗式审查另做一轮：恶意文本、重复记录、缺失月份、坏书封、连续导出、空选择和数据口径冲突。

动态图表另运行`tests/reading_html_art.cjs`：核验真实动画对象、滚入完成、连续重播清理、缩放后细线可见、减少动态效果、打印最终帧和分数刻度。先生成一份含已知／未知逐书时长的测试年鉴，不能用纯静态检查替代浏览器验证。
