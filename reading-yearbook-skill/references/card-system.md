# 卡片系统

这是旧档案模式模板的维护说明，只用于 `render_yearbook.py` 的兼容任务。它的年轮、色板与分类版式不约束默认分享；当前分享使用[HTML年鉴流程](html-yearbook.md)中的同一画布。

## 视觉立场

主题是“时间在纸上留下阅读轨道”。纸张、墨色和细线来自档案，不是复古装饰；书籍年轮是唯一高识别元素。

色板：

- 纸白 `#F1EADC`
- 深纸 `#E3D7C3`
- 墨黑 `#1D1C19`
- 注释灰 `#6B645A`
- 年度强调墨绿 `#245B59`
- 线色 `#B9AD9A`

标题优先使用本机 `Iowan Old Style` 与 `Songti SC`；正文使用 `Avenir Next` 与 `PingFang SC`；数据使用等宽字体。没有字体时使用模板内置回退，不联网加载字体。

## 版式

- 竖向线索卡：小说、随笔、人物；内容按“遇见—重点—思考”向下展开。
- 对页卡：社科、思想、文化；左侧书籍，右侧用户，中线表示关系。
- 折页卡：商业、工具、方法；三列分别放问题、线索和个人思考。

正式产物按内容形状选择：文学、小说、随笔与人物类用竖向线索卡；商业、管理、工具与教育类用折页卡；其他思想、社会与文化类用对页卡。不要按顺序机械轮换。

正式卡组至少包含：年度封面、阅读节律、反复主题、年度之书、精选单书和留给下一年的问题。`cards-manifest.json` 记录每张卡的类型、文件、版式和生成状态。

## 尺寸与可读性

- HTML 卡片逻辑尺寸 900×1200，即 3:4。
- 正文字号不低于 20px，分享图不得靠缩小文字容纳内容。
- 超长内容在档案中保留，卡片只放一个重点。
- 必须支持键盘焦点；无必要动画。图谱尊重 `prefers-reduced-motion`。
