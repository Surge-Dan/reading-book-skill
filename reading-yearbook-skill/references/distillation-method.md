# 深度蒸馏

只在用户主动提供有权处理的 PDF、EPUB、TXT 或 MD 时读取并执行。

## 目标

把全文中的论证与方法转成可解释、可执行、可验证的能力，不把书评、金句或模型常识直接包装成子 Skill。

## 输出

1. 结构：核心问题、章节关系、论证路线。
2. 能力：方法、步骤、输入、输出、适用场景。
3. 边界：反例、失败条件、不适用场景。
4. 证据：每项能力对应的原文位置或章节。
5. 测试：正向、反向和边界问题。

## 子 Skill 门槛

只有一项能力同时满足以下条件才可升格：

- 能解释：能说清为什么这样做。
- 能执行：该方法所在证据段落有可操作步骤或判断标准。
- 能验证：同一证据段落说明如何观察结果、比较反例或发现失败。
- 有边界：同一证据段落说明何时停止、何时不适用或有哪些风险。

脚本生成的 `generated-skill` 只是候选，必须人工核对后再安装。创建候选 Skill 时必须显式传入 `--full-text-confirmed`；至少两条候选方法逐条通过“步骤、验证、边界、测试”门槛并带段落 `source_id`，才允许写出候选 Skill。frontmatter 必须先经过名称与安全引用检查。PDF 若缺少 `pypdf`，明确标记未验证；不要改用网络下载正文。
